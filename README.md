# Skyward Glide

A 3D glider game in a single HTML file (Three.js). Glide forward and down through ten themed worlds, dodge obstacles, thread tunnels and punch through waterfalls.

**Play:** open `index.html` in a browser, or use the GitHub Pages link in the repo sidebar.

## Levels (about 5 minutes each, faster and harder as you go)

1. **Frostpeak Glacier**: pine forests, ice caves, ice falls
2. **Emerald Jungle**: giant trees, rivers, waterfalls
3. **Sunscorch Canyon**: hoodoos, cacti, sandfalls
4. **Magma Core**: obsidian spikes, lava rivers, lavafalls
5. **Midnight Festival**: night city, lanterns, fireworks
6. **Deep Space**: asteroids, ringed planet, warp conduits
7. **Mirror Land**: chrome world with a mirrored ceiling
8. **Crystal Caverns**: glowing geodes underground
9. **Neon Grid**: synthwave sunset and laser curtains
10. **The Multiverse**: a portal every 30 seconds jumps you to another world

## Controls

| Action | Keys |
| --- | --- |
| Steer | ← → or A / D |
| Climb / dive | ↑ ↓ or W / S |
| Mouse / touch | drag anywhere to steer |
| Pause | P or Esc |
| Sound | M |
| Invert up/down | I |

You have 3 wings (lives) per run. Checkpoints come every 20% of a level. Rings, tunnels and waterfalls give bonus points.
